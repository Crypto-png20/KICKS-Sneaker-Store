# KICKS - Sneaker Selling Store (TW-1)

## Requirements implemented
1. Landing Page - `index.html`
2. Product Display Page - `products.html`
3. Shopping Cart View Page - `cart.html`
4. Payment Page - `payment.html`
5. GitHub repository - upload this folder to a GitHub repository

## Technologies
- HTML
- CSS
- JavaScript
- localStorage for cart data

## Features
- Responsive layout for desktop, tablet and mobile
- Navigation between all pages
- Product cards with sizes
- Add to Cart
- Quantity increase/decrease
- Remove from cart
- Automatic subtotal, delivery and total calculation
- Payment form validation
- Demo order confirmation

## Run
Open `index.html` in a browser. Internet is required for the online sneaker images.

## GitHub Pages
Create a GitHub repository, upload all files/folders, then go to:
Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save

Do not enter real payment card information. The payment page is only a classroom demo.
